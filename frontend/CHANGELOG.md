# DellDi SQL 助手前端更新日志

本文档记录 DellDi SQL 助手前端项目的所有重要变更。

## [0.1.3] - 2025-05-10

### 📚 功能增强
* 🌐 实现用于添加训练数据的API端点，提升模型的SQL生成能力
* 📬 引入新的`TrainResponse`模式以确保API响应的一致性，并返回训练数据ID
* ♻️ 重构代理以正确获取路径参数
* 💻 更新前端以Markdown格式展示训练数据
* 👁️ 优化训练数据表格的展示效果，增强可读性
* 💾 改进数据处理逻辑，确保训练数据的正确存储和展示

## [0.1.2] - 2025-05-10

### 🛠️ 技术改进
* 🔗 新增 Next.js API 代理层，优化前端与后端的通信
* 📝 添加 `/api/proxy` 路由，实现对后端 API 的透明代理
* 💡 保持原有 API 调用方式不变，实现无缝迁移
* 📊 改善浏览器网络控制台中的接口调用可见性
* 💾 添加通用请求处理函数，简化 API 调用代码

## [0.1.1] - 2025-05-10

### ✨ 功能增强
* 🚀 新增基于 react-markdown 和 react-syntax-highlighter 的富文本渲染器
* 🎨 支持 Markdown 语法渲染，包括标题、列表、表格、代码块等
* 💡 代码块支持语法高亮，自动识别超过 40 种编程语言
* 📋 添加代码复制功能，支持一键复制代码内容
* 🌓 优化暗色/亮色主题切换，提高文本对比度和可读性
* 🔗 支持自动识别并格式化链接，外部链接自动添加新窗口打开属性

### 🎨 UI/UX 改进
* 💄 为不同 Markdown 元素添加自定义样式，提升整体美观度
* 🌈 优化代码块显示效果，添加语言标签和复制按钮
* 📱 改进移动端适配，确保在各种屏幕尺寸下的良好显示效果
* 🔍 增强内联代码的可读性，添加背景色和边框样式

### 🛠️ 技术改进
* 📦 升级依赖包，使用最新版本的 react-markdown (v10.1.0)
* 🧩 添加 remark-gfm 插件，支持 GitHub Flavored Markdown
* 🔄 使用 rehype-raw 插件，支持 HTML 内容渲染
* 🎯 使用 TypeScript 类型定义，提高代码质量和开发体验
* 📏 优化 CSS 结构，使用 Tailwind CSS v4 规范

## [0.1.0] - 2025-05-05

### 🚀 初始版本
* 🏗️ 搭建基于 Next.js 15 和 React 19 的前端框架
* 🎨 集成 Tailwind CSS v4 和 shadcn/ui 组件库
* 💬 实现基础聊天界面，支持用户提问和 AI 回答
* 📊 添加 SQL 查询结果展示功能
* 📈 支持数据可视化图表生成
* 📁 实现数据导出功能
* 🔄 添加 SQL 重新生成功能
* 💡 支持跟进问题建议功能
* 🌓 实现深色/浅色主题切换
* 📱 支持响应式布局，适配桌面和移动设备
