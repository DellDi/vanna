# 更新日志

## [0.2.3] - 2025-05-07

### 🔄 架构重构
* 📚 将路由按功能分组拆分为四个模块：基础、问题记录、训练、拓展能力
* 🛠️ 优化代码结构，提高可维护性
* 🔧 将Vanna实例初始化移动到app.py，统一管理
* 📝 为每个路由模块添加标签，改善API文档组织

## [0.2.2] - 2025-05-07

### 💶 功能增强
* ✨ 新增`delete_question`接口，支持删除问题记录及相关数据
* 📝 完善前端 API 调用支持，实现`deleteQuestion`函数

## [0.2.1] - 2025-05-06

### 📦 模型迁移与数据库支持
* ✨ 新增数据库模型结构，支持PostgreSQL数据库
* 📝 将API模型定义迁移到`models/schemas.py`
* 💾 添加SQLAlchemy ORM数据库模型定义
* 🔧 实现数据库配置和连接管理
* 📚 采用仓库模式封装数据库操作
* 🔄 添加数据库初始化脚本
* 💬 新增`generate_summary`接口生成数据摘要
* 📝 更新README文档，添加数据库模型和配置说明
* 💬 新增`generate_rewritten_question`接口，支持问题重写功能

### 🐛 错误修复
* 🔧 完善`require_cache`依赖注入函数，增加可选字段支持
* 📡 改进错误日志输出，提供更详细的错误信息
* 🔄 优化`load_question`接口，增强异常处理
